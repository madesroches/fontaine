The attachment is inserted at the cursor as a dim inline token, part of the text buffer itself (Backspace deletes it like any character; no chip row, no hit-testing). The sent message is parsed back into a text part plus an image part. Trade-off: the smallest possible change to the input view, but no thumbnail, no per-chip removal affordance, and a long filename wraps awkwardly inside the typed line.
