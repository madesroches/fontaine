Option B — spinner as the transcript tail

The spinner is the last live line of the transcript, directly under whatever is streaming (reasoning card, tool row, answer). It reads as part of the conversation. Trade-off: it is a new live-area element, so commit_within/live_lines height budgeting must account for it and it must never be written to scrollback.
