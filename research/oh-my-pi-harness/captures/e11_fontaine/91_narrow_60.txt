**What was wrong:** `stats.median` always returned `ordered[
mid]`. That is correct only for odd-length input; for even-l
ength input it returned the upper middle element (`3` for `[
4, 1, 3, 2]`) instead of the mean of the two middle elements
 (`2.5`).

**Fix** (`stats.py`):
```python
    ordered = sorted(values)
    mid = len(ordered) // 2
    if len(ordered) % 2:
        return ordered[mid]
    return (ordered[mid - 1] + ordered[mid]) / 2
```
